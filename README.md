## Research Focus

I study how LLM-based agents can help people think more clearly — especially in ambiguous, high-stakes decisions. My work sits at the intersection of **human-AI interaction**, **reflective reasoning**, and **decision traceability**.

Concretely, I'm interested in:
- How role-based agents (counterpart, observer, future self) support perspective-taking and reduce decision bias
- How to design traceable, evidence-constrained decision workflows that preserve user autonomy
- How reflective AI tools can externalize assumptions and make reasoning legible

## Prototype Portfolio

### 🔍 What-if · Reflective AI for Complex Decision-Making
> [Live Demo](https://what-if.myrawzm0406.online/)

Transforms user narratives into structured decision scenarios — roles, causal chains, assumptions, and alternative what-if paths. Explores evaluation dimensions including reflection depth, perspective diversity, cognitive load, decision confidence, trust, and perceived decision ownership.

**Key design choices:** bilingual (EN/ZH) · role-based agent architecture · scenario decomposition · Memorial Award, Memory Genesis Competition 2026

### 🧠 User Research Agent · Decision Memory Prototype
> [Live Demo](https://user-insight.myrawzm0406.online/)

An agent that routes B2B diagnostic inputs into structured research plans, interview guides, and survey drafts. Designed around a **traceable decision-memory workflow**: citation-based enforcement, conflict recall, and evidence-constrained future decisions.

**Research question it explores:** How can agents support structured sensemaking without overriding user judgment?

### 📊 Agent-Assisted User Research & Decision Support OS
